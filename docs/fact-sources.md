## 当前事实状态

- 七个景点、六条路线、五类成果均为可配置演示数据；坐标、里程、时长、开放、票务、人物、数据指标等未获负责人确认，因此统一保持“规划中/待确认”。
- 地图底图不是导航地图；没有 GCJ-02 坐标时不绘制貌似精确的 Marker 或线路。
- 证书是旅行纪念演示，不代表官方认证、宗教认证或行政证明。
- 后台数据是 `local-demo`，仅保存到当前浏览器。

字段级状态、冲突处理和来源模型详见 `docs/fact-ledger.md`。最终发布前应由项目方提供唯一景点清单、路线坐标/轨迹、开放信息和书面确认日期。
