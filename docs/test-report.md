Playwright 初次运行发现 3 项：两处验收断言使用了不存在的文案/旧路由，以及后台 390px 导航造成 136px 页面溢出。修复测试基准与移动导航约束后，新鲜运行 22/22 通过；其中 Hero 媒体探针确认 1536×1024、约 10 秒、静音且无控制台错误。

Playwright 自带 Chromium 因网络超时无法下载；按用户指定浏览器，配置改为调用本机正式版 Chrome，实际浏览器验收已完成，不以 HTTP 健康检查替代。

构建观察：Three.js 与 PLYLoader 仅在 3D 路由动态加载；ECharts 在后台图表组件内动态加载。其独立 chunk 体积较大，但不会进入公共首页初始模块。

本报告中的“通过”仅覆盖实际执行的自动化与浏览器 smoke。它不代表 WCAG 2.2 AA 合规认证，也不代表 LCP ≤2.5s、CLS ≤0.1、INP ≤200ms 已经测得或通过。
