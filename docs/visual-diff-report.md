# 视觉差异报告

## 证据

- 参考：`references/prototypes/` 的 P01–P32 原始 PNG。
- 实现：`output/playwright/screenshots/`，系统 Chrome、deviceScaleFactor 1。
- 同尺寸对照：`output/playwright/comparisons/P01-comparison.png` 等 12 组；左右均为 1487×1058。
- 响应式补充：主页与景点页在 1440×1024、768×1024、390×844、1920×1080 的首屏截图。

## 结论

严格像素验收结果：**FAILED / PARTIAL**。计划要求的视觉差异 ≤1% 未达到。已测代表帧的全画面差异覆盖率为 P01 52.4%、P06 65.1%、P09 92.2%；12/32 帧已生成同尺寸对照，其余 20 帧只有路由/功能映射，没有直接视觉对照，不能宣称全站像素验收完成。

P01、P06、P19 和后台 P27–P32 保留原型的信息层级与大体视觉语言，但仍存在可见布局、图像和字形差异。P05 因没有已核验坐标而不绘制貌似精确的路线与 Marker；P09 因没有真实模型而保持不可用降级。这些处理符合事实边界，但仍然构成相对原型的显著视觉差异。

## 五项表面检查

- 字体：标题使用 Noto Serif SC/宋体回退，正文使用 Noto Sans SC/系统黑体回退；层级与换行稳定。未随包分发字体，因此不同系统字面细节可能略有差异。
- 间距：采用 8px 节奏、统一页面容器和卡片间距；五档视口均无公共页面横向溢出，后台移动溢出已修复。
- 色彩：米白、墨绿、暗金、朱砂均由共享令牌控制；状态色具有文字说明，不只依赖颜色。
- 图像：页面使用用户品牌文件、ImageGen 原创素材及 AVIF/WebP 响应式版本；未用整页截图、CSS 图形或手绘 SVG 充当可见资产。
- 文案：未核验信息显示“规划中/待确认”；AI 与离线地图有可见披露；后台明确“本地演示”。

## 阻塞项

- 仍有 20 张原型未生成同尺寸视觉对照。
- P01、P06、P09 已测差异均远高于 1%，属于未关闭的 P1 视觉问题。
- 正式字体、景点照片、路线坐标和 3D 模型未提供，相关页面无法完成严格像素验收。
