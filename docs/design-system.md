# 共享设计系统基线

本文件记录 Task 1 的固定视觉令牌。后续页面只能使用这些计划值；新增令牌须先说明用途并通过设计 QA，不得用近似色替换。

## 布局

- 基础间距单位：8px。
- 桌面设计画布：1280px。
- 桌面左右边距：80px；内容宽度：1120px。
- 栅格：12 列，列间距 24px。
- 导航高度：桌面 72px，紧凑/响应式状态 64px。
- 响应式断点：640px、768px、1024px、1280px；信息层级不因重排而消失。

## 动效

| 用途 | 固定时长 |
| --- | --- |
| 内容揭示 | 600ms |
| 悬停反馈 | 200ms |
| 环境循环 | 2000ms |
| 路由/章节过渡 | 800ms |
| 控件反馈 | 250ms |

`prefers-reduced-motion: reduce` 下必须关闭平滑滚动，将非必要动画压缩到近乎即时，并保留完整信息与控件状态。动效不承担唯一的信息表达。

## 品牌与可访问性

- 高清 Logo 文件尚未复制到工程前，使用纯文字“六祖云游 / 云浮文化旅游”锁定；不得用 CSS 绘制印章或伪 Logo。
